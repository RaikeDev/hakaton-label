# Kamik Label Portal

Рабочий кабинет музыкального дистрибьютора для артистов и команды лейбла.

Проект объединяет каталог треков, аналитику, AI-инсайты, согласования релизов, sync-кейсы, баланс, выплаты и загрузку отчетов по роялти. Главная идея: артист видит не просто статистику, а понятную картину по релизам, деньгам и следующим действиям.

## Что важно по данным

- Отчеты платформ и дистрибьюторов загружаются в панели администратора.
- После загрузки данные попадают в нашу PostgreSQL-базу: статистика треков, доходы, транзакции.
- Личные кабинеты артистов и внутренние разделы читают данные из этой базы.
- DataLens не является местом загрузки отчетов. Он подключается к нашей базе и строит внешние графики поверх уже загруженных данных.

## Возможности

- Авторизация артиста и администратора.
- Дашборд с доходом, балансом, топ-треками и платформами.
- Каталог треков с ISRC, статусами, прослушиваниями и доходом.
- Аналитика по платформам, периодам, географии и трекам.
- Встраиваемый DataLens-дашборд, привязанный к конкретному личному кабинету артиста.
- AI-раздел с операционными инсайтами по каталогу.
- Баланс и история транзакций.
- Выплаты со статусами: согласование, перевод, оплата.
- Согласования релизов с этапами проверки.
- Sync-кейсы для рекламы, кино и сериалов.
- Глобальный поиск по разделам, действиям, трекам и ISRC через `Ctrl+K`.

## Загрузка отчетов

В панели администратора откройте `Загрузка отчетов`.

Можно показать два сценария:

1. `Запустить демо-импорт` — backend берет готовый файл `demo-data/royalty_report_march.csv`.
2. `Загрузить и обработать` — пользователь выбирает CSV/XLSX файл вручную. Для демонстрации подходит `demo-data/sample_royalty_report_upload_excel.csv`.

После обработки система:

- проверяет обязательные колонки;
- сопоставляет артиста, трек, ISRC и платформу;
- обновляет статистику треков;
- рассчитывает долю артиста и лейбла;
- создает или обновляет доходные транзакции;
- показывает результат импорта без дублей при повторной загрузке периода.

Дальше эти данные видны в финансовом сценарии:

- `Баланс` показывает начисления, выплаты и историю операций;
- `Выплаты` показывает реестр платежей со статусами `На согласовании`, `Готово к переводу`, `Выплачено`;
- при отметке перевода backend создает исходящую транзакцию выплаты в балансе.

## DataLens

DataLens используется как внешний источник готовых отчетов. Мы не загружаем сторонние файлы в DataLens и не объединяем их внутри DataLens.

Правильная схема:

```text
DataLens -> готовый отчет / ссылка / iframe
        -> наша платформа
        -> привязка отчета к конкретному ЛК
        -> показ отчета пользователю
```

В нашей базе у артиста хранится поле `datalens_url`. Это связь между личным кабинетом и отчетом DataLens:

| ЛК / artist_id | DataLens URL |
| --- | --- |
| `1` | ссылка на отчет DataLens для артиста 1 |
| `2` | ссылка на отчет DataLens для артиста 2 |
| `3` | ссылка на отчет DataLens для артиста 3 |

DataLens отдельно строит отчет, а платформа решает, кому какой отчет показать. В разделе `Аналитика` frontend берет `datalens_url` из данных текущего артиста и показывает соответствующий iframe.

В интерфейсе это видно в трех местах:

- на `Дашборде` показан статус Yandex DataLens и переход в аналитику;
- в `Аналитике` есть отдельный блок схемы `DataLens -> Платформа -> ЛК артиста` и встроенный iframe;
- в админском разделе `Артисты` есть управление связью `artist_id -> datalens_url`.

Для демо можно записать ссылку вручную в базу:

```powershell
docker exec kamik-db psql -U kamik -d kamik -c "UPDATE artists SET datalens_url = 'https://datalens.yandex.ru/ВАША_ССЫЛКА' WHERE id = 1;"
```

## Демо-сценарий

1. Войти артистом.
2. Показать дашборд: доход, баланс, топ треков, платформы.
3. Открыть аналитику и переключить периоды.
4. Показать DataLens-блок внизу аналитики, если ссылка настроена.
5. Открыть глобальный поиск через `Ctrl+K`.
6. Показать каталог треков и карточку трека.
7. Показать AI-инсайты как помощника по решениям для каталога.
8. Показать баланс, выплаты, согласования и sync-кейсы.
9. Переключиться в режим администратора.
10. Показать артистов лейбла и загрузку отчетов.
11. Загрузить пример CSV и показать, что данные обновились без дублей.
12. Открыть `Баланс` и показать новые доходные операции.
13. Открыть `Выплаты`, показать статус `Готово к переводу` и действие администратора.
